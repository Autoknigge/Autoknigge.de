🔑 1. Zugang
Wie bekomme ich einen Token?
  1. GitHub öffnen → Profilbild → Settings → ganz unten Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name z. B. „Autoknigge Upload“, Ablauf z. B. 90 Tage.
  4. Only select repositories → nur dein Autoknigge-Repository wählen.
  5. Unter Repository permissions → Contents auf Read and write stellen.
  6. Erzeugen und den Token einmal hier einfügen. Er wird nur einmal angezeigt.
Der Token gehört wie ein Passwort nur dir. Gib ihn niemandem und lade diese Datei nicht öffentlich hoch. Wenn du ihn nicht mehr brauchst, löschst du ihn bei GitHub.
